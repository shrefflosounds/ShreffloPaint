# ShreffloPaint 🎨✨

**ShreffloPaint** is a customized version of Tux Paint, featuring custom decals, sounds, stamps, and a new png to stamp Magic Tool, with the option to save to the stamp collection.

## 🚀 Installation Instructions

### macOS
1. Download **`ShreffloPaint-macOS.dmg`** (or `.zip`).
2. Open the `.dmg` and drag **ShreffloPaint.app** into your **Applications** folder.
3. If macOS displays a Gatekeeper prompt on first launch ("unidentified developer"), right-click (Control-click) `ShreffloPaint.app` and choose **Open**, then click **Open**.

### Windows
1. Download **`ShreffloPaint-Windows.zip`**.
2. Extract the ZIP archive to any folder (e.g., `Desktop` or `Documents`).
3. Double-click **`ShreffloPaint.exe`** to start painting right away! No installation required.

## 🛠️ Adding Custom Stamps Manually

You can add any PNG image directly into ShreffloPaint:
- Ideal dimensions: up to **300 × 300 pixels** (aspect ratio preserved).
- Format: 32-bit RGBA PNG with transparent background.
- On macOS, place files into:
  `~/Desktop/ShreffloPaint.app/Contents/Resources/share/tuxpaint/stamps/00_shrefflo/`
- On Windows, place files into:
  `data/stamps/00_shrefflo/`
